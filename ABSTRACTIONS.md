# Ginko CMS Abstractions

This document names the core concepts used across the implementation and docs.

## Ginko Core

The provider-neutral Nuxt content engine. Ginko core owns website-facing content
APIs and keeps Nuxt page code independent of where content comes from.

## Ginko CMS

The CMS/admin layer for Ginko. It owns Studio, Convex-backed content storage,
Better Auth integration, assets, public projections, owner-CLI content
portability, MCP, and the provider that lets Ginko core read published CMS
content.

## CMS Contract

A code-defined contract supplied by the host app. The installed CMS contract is
the single source for collection schemas, locales, content policy, and
editorial presentation, with separate content and presentation hashes.

Studio and MCP inspect the installed contract. They do not create or mutate it.

## Studio

The authenticated human editing surface. Studio is a standalone Vite SPA hosted
by the Nuxt module. It manages content operations, not schema authoring.

## MCP Surface

The authenticated agentic operation surface. MCP exposes tools, resources, and
prompts for CMS workflows such as inspecting content, drafting, translating,
validating public routes, explaining visibility, and preparing publish impact.

MCP is first-class but opt-in.

## Public Projection

A published, website-shaped read model generated by CMS operations. Public
website reads use active projections instead of draft/editor tables.

## Ginko Provider

The primary Nuxt website integration. The provider adapts active CMS projections
to Ginko core so app page code can stay provider-neutral.

## Public HTTP API

A supported published-read integration surface for advanced and non-default
consumers. It should not replace the CMS provider as the primary Nuxt path.

## Canonical Body Source

Raw MDC is the canonical editable body source for v1. Rich editors and public
render forms are adapters around that source.

## Stable Relation Reference

Relation fields store stable entry references. Ginko CMS does not promise a v1
runtime expansion/depth/include query API.
